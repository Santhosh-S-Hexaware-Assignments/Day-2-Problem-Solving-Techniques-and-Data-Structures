# Set 1 – E-Commerce Catalogue and Traffic Analysis

## Decision Table

| Problem | Data Structure / Pattern | Reason |
|:---|:---|:---|
| Product Category Search | Binary Search Tree (BST) | Supports efficient insertion, searching and sorted traversal of product categories. |
| SKU Lookup | Hashing / Hash Map | Enables fast key-based lookups and demonstrates collision handling. |
| Microservice Dependencies | Graph (BFS / DFS) | Represents service dependencies, determines deployment order and detects circular dependencies. |
| Peak Traffic Analysis | Sliding Window | Identifies the busiest continuous 3-hour window efficiently. |
| Gift Card Matching | Two Pointers | Finds all pairs of order values matching the target without using nested loops. |
